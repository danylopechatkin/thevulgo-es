# SEO intent map

| Intent | Primary English URL | Primary Spanish URL | Conversion action |
|---|---|---|---|
| Broad handyman / home installation | `/` | `/es` | General WhatsApp quote |
| TV mounting Valencia | `/montaje-tv-valencia` | `/es/montaje-tv-valencia` | TV details by WhatsApp |
| Handyman Valencia / multiple jobs | `/handyman-valencia` | `/es/handyman-valencia` | Send job list and photos |
| Furniture / IKEA assembly | `/montaje-muebles-valencia` | `/es/montaje-muebles-valencia` | Send product list/photos |
| Kitchen assembly | `/kitchen-assembly-valencia` | `/es/montaje-cocinas-valencia` | Send plan/photos or estimator |

Supporting URLs must link back to the matching primary intent page. A new URL is justified only when the query needs a meaningfully different service scope, evidence or conversion flow.

## Cannibalisation rule

If two pages answer the same query and offer the same next action, retain the stronger URL, merge useful content and permanently redirect the weaker URL. District pages remain only where they contain genuine local service information and demand.
