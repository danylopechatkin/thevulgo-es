# Valencia renovation price research — 17 September 2026

Internal working document. This is not public website copy.

The public catalogue uses integer cents in `lib/renovationCatalog.ts`. Predictable, tightly scoped work uses fixed, unit, hourly, linear-metre or square-metre pricing. Work with concealed conditions, several trades, permissions or structural implications uses a project quotation.
